# Complex Matrix Calculator

Практическая работа №1 (Java): класс для работы с матрицами комплексных чисел и консольный интерфейс к нему.

## О проекте

**Ситуация.** В рамках первой практической работы по Java нужно было
научиться проектировать классы, работать с исключениями и консольным вводом-выводом.
В Java нет встроенного типа для комплексных чисел и нет перегрузки операторов,
поэтому всю арифметику пришлось описывать самостоятельно.

**Задача.** Написать класс для работы с матрицами комплексных чисел:
сложение, умножение, деление (где это возможно), транспонирование и определитель.
К классу нужен консольный интерфейс, в котором можно создать матрицу и выбрать
операцию. Результат последней операции должен сохраняться на время работы
программы, чтобы его можно было использовать дальше.

**Действия.**
- Написал класс `Complex` с операциями над комплексными числами. Деление на ноль
  вызывает `ArithmeticException`.
- Написал класс `ComplexMatrix`. Каждая операция возвращает новую матрицу, поэтому
  операции можно соединять в цепочку.
- Определитель считается методом Гаусса, обратная матрица методом Гаусса-Жордана,
  а деление реализовано как `A / B = A * B^-1`.
- Для невозможных операций (разные размеры, неквадратная или вырожденная матрица)
  бросаются исключения с понятным текстом.
- Написал консольное меню в `Main`: ввод матриц с проверкой данных, выбор операции,
  перехват исключений и хранение последнего результата.
- Проверил программу вручную на примерах (в том числе с комплексными числами),
  сверяя результаты с расчётами на бумаге.

**Результат.** Получилась программа, которая выполняет все требуемые
операции над матрицами комплексных чисел. Она не падает при неверном вводе или
невозможной операции, а выводит сообщение и возвращается в меню. Результат
последней операции можно использовать в следующей, например, прибавить к нему
третью матрицу.

## Что умеет программа

- сложение матриц;
- умножение матриц;
- деление матриц (`A / B = A * B^-1`, если `B` квадратная и невырожденная);
- транспонирование;
- вычисление определителя (метод Гаусса).

Результат последней операции сохраняется на время работы программы, и его можно
взять как одну из матриц в следующей операции (например, прибавить к результату
третью матрицу). Сохранённый результат можно посмотреть отдельным пунктом меню.

Если операцию выполнить нельзя (например, у матриц разные размеры или
матрица вырожденная), программа выводит сообщение об ошибке и возвращается в меню.

## Структура проекта

```
src/
  Complex.java        - комплексное число и арифметика над ним
  ComplexMatrix.java  - матрица комплексных чисел и операции над ней
  Main.java           - консольный интерфейс
```

## Как запустить

Нужна установленная Java (JDK 8 или новее). Из корня репозитория:

```
javac -encoding UTF-8 -d out src/Complex.java src/ComplexMatrix.java src/Main.java
java -cp out src/Main
```

## Как вводить данные

Размеры матрицы вводятся целыми числами (от 1 до 10). Каждый элемент вводится
отдельной строкой: два числа через пробел, действительная и мнимая части.

| Ввод   | Число |
|--------|-------|
| `3 -2` | 3 - 2i |
| `0 1`  | i |
| `5`    | 5 |
